Notepad for daily editing

A lightweight editor that keeps your files honest.

X-Pad is a Notepad / Notepad++ / Atom-style editor built with .NET 10, Avalonia UI, and AvaloniaEdit (TextMate highlighting). Tabs, session restore, encodings that round-trip, and optional LSP — without the IDE weight.

docs for 0.5.1

Overview

  • Tabs & session Dirty close prompts, restore files + unsaved buffers + caret, reopen closed tabs.
  • Syntax & themes TextMate highlighting; Dark, Light, System, Monokai, Hacker, AMOLED, GitHub.
  • Shortcuts VS Code-style defaults (Ctrl+P Quick Open, Ctrl+D multi-cursor, Ctrl+B Explorer).
  • Find everywhere In buffer, open tabs, or folder — case, whole word, regex.
  • File fidelity Encoding, BOM, and CRLF/LF/CR preserved on save.
  • Workspace Open Folder explorer; find/replace on disk under the root.
  • Optional LSP Hover, definition, references, workspace symbols, outline, code actions, rename.

Settings and recovery live under %APPDATA%\XPad\ (settings.json, session.json, recovery/).

Run & install

From source

dotnet restore
dotnet build
dotnet run
dotnet test

Open a file, create an empty buffer, or open a folder:

dotnet run -- path\to\file.txt
dotnet run -- new-notes.txt    # empty buffer; Save creates the file
dotnet run -- path\to\folder
xpad --help

Global xpad via Bun link

dotnet build -c Release
bun link
xpad path\to\file.txt

scripts/xpad.js launches bin/Release/net10.0/xpad.exe. A second launch hands files to the running instance.

Windows publish

pwsh scripts/publish-win-x64.ps1
pwsh scripts/install-open-with.ps1 -ExePath .\publish\win-x64\xpad.exe

Adds Send to → X-Pad and per-user Open with for common text/code types. It does not replace notepad.exe as the system default. Use -Mode selfcontained for a single-file self-contained publish.

Microsoft Store (MSIX)

Listing: apps.microsoft.com/detail/9p88nmm8f1wl (product 9P88NMM8F1WL).

Fallback (no custom element): 

# Local sideload (default XPad.Dev identity)
pwsh scripts/publish-msix.ps1 -Install

# Store upload — Partner Center identity
pwsh scripts/publish-msix.ps1 `
  -PackageName "<identity name>" `
  -Publisher "<CN=...>" `
  -PublisherDisplayName "<publisher display name>"

Needs the Windows SDK (makeappx). Store/MSIX installs skip the GitHub updater. Listing needs screenshots, box art, a privacy policy URL, and an IARC age rating. A Partner Center UI draft submission blocks CI msstore publish until that draft is gone.

Editing

  • Find / replace in the current buffer; find/replace in open tabs (Ctrl+Shift+F) and in the workspace folder (Ctrl+Shift+H).
  • Bookmarks, bracket match/jump, multi-occurrence edit, rectangular selection (Alt+drag).
  • Per-tab word wrap (Alt+Z); Preferences Word Wrap is the default for new tabs only.
  • Per-buffer tabs vs spaces, detected from leading whitespace; status-bar toggle.
  • Encoding + BOM + line endings preserved; re-decode from kept source bytes (UTF-8 / BOM / UTF-16 LE+BE / Latin-1).
  • Read-only from file attributes or File menu; status-bar RO.
  • Large-file guard (above 8 MB): plain open, skip folding / word completion / full-text LSP.
  • Crash recovery for dirty/untitled buffers; clean exit clears recovery/.
  • Optional autosave, .bak backup on save, trim + final newline on save.
  • Command palette (Ctrl+Shift+P), Quick Open (Ctrl+E), embedded terminal (Ctrl+`).

Language tools

TextMate grammars drive syntax highlighting. Override the language from the status bar when the extension guess is wrong.

Word completion (Ctrl+Space) works without a server. Optional stdio language servers are configured in Preferences → Language servers:

  • Hover and diagnostics (squiggles)
  • Go to definition (F12)
  • Find references (Shift+F12)
  • Document outline (Ctrl+Shift+.)
  • Go to symbol in workspace (Ctrl+T)
  • Code actions with text edits (Ctrl+.)
  • Rename symbol (Ctrl+Shift+R)

Missing servers are ignored. LSP rootUri follows the Open Folder workspace when one is set.

An external formatter command ($FILE placeholder) can run on save or via Format Document (Shift+Alt+F).

Settings & updates

Under %APPDATA%\XPad\:

  • settings.json — editor prefs, LSP commands, recent files, update prefs
  • session.json — last open files + caret (and unsaved buffer text)
  • recovery/ — dirty/untitled snapshots (cleared on clean exit)

Preferences (Ctrl+,) use a sidebar: Editor, Saving, Appearance, Formatter, Language servers, Updates.

Updates. Help → Check for Updates queries GitHub Releases. Published installs can update in place after you confirm. Store/MSIX installs use the Store instead. Startup checks run at most every 12 hours and never download until you confirm.

Cut a release with pwsh scripts/release.ps1 (patch bump by default). Tag push runs the release workflow and attaches the Windows zips.
