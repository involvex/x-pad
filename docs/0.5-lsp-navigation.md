# 0.5 Design sketch: LSP go-to-definition + outline

Status: **approved intent** (proceed after 0.4.0) — lite navigation on top of workspace `rootUri`.

## Intent

Use the optional stdio LSP for jump-to-definition and a document outline, without becoming a full IDE. Workspace root from 0.4 already feeds `initialize.rootUri`.

**Success:**

- F12 / Go to Definition opens or focuses the target file and caret (same window).
- Outline panel or palette list from `textDocument/documentSymbol`; click jumps.
- Missing / unsupported servers: status message, no crash (same soft-fail as today).

## Scope (0.5)

| In | Out |
| --- | --- |
| `textDocument/definition` | Rename, code actions, references UI (optional stretch: peek references later) |
| `textDocument/documentSymbol` → outline list | Workspace symbol search |
| Wire menus + command palette + status | Custom LSP UI chrome beyond existing dialogs |

## Approach

1. Extend `LspClient` capabilities + `DefinitionAsync` / `DocumentSymbolsAsync` with location parsers (Location | Location[] | LocationLink[]).
2. `MainWindowViewModel` / `DocumentEditor`: Go to Definition at caret; Outline window listing symbols.
3. Open path from `file://` URI via existing `OpenFileFromPath` + `GoToMatch` / caret restore.
4. Unit-test JSON parsers with frozen LSP payloads (no live language server required).

## Release

Ship as **0.5.0** after the batch (`pwsh scripts/release.ps1 -Bump minor`).
