# 0.8 Design: LSP workspace symbols

Status: **implemented** — `workspace/symbol` with a query list and jump via the existing definition path; URI-only hits call `workspaceSymbol/resolve` when the server advertises `resolveProvider`.

## Intent

Jump to a named symbol anywhere in the language server’s workspace without becoming a full IDE. Reuse `OpenFileFromPath` + `GoToMatch` from Go to Definition / Find References.

**Success:**

- Find → Go to Symbol in Workspace / `Ctrl+T` / command palette.
- Query prompt is prefilled with the word at the caret (empty query is allowed).
- Hits are capped (200). One hit jumps immediately; several open a list (name, container, file:line).
- URI-only locations resolve via `workspaceSymbol/resolve` when supported; otherwise open at the start of the file with a status message.
- Missing / unsupported servers: status message, no crash.
- Outline (`Ctrl+Shift+.`) stays current-document `textDocument/documentSymbol`.

## Scope

| In | Out |
| --- | --- |
| `workspace/symbol` (SymbolInformation and WorkspaceSymbol) | Peek / side-by-side |
| `workspaceSymbol/resolve` when `resolveProvider` is set (URI-only → range) | Lightbulb, `executeCommand` |
| Query prompt + results list + jump | Fuzzy ranking beyond the server’s list |
| Menu + palette + `Ctrl+T` | |
| Soft-fail when the server omits `workspaceSymbolProvider` | |

## Approach

1. Advertise `workspace.symbol` (with `resolveSupport.properties: ["location"]`) on initialize; record `workspaceSymbolProvider` and `resolveProvider`.
2. `LspNavigationParser.ParseWorkspaceSymbols` for `SymbolInformation[]` / `WorkspaceSymbol[]`. Keep original JSON on `Raw` and set `HasRange` from whether `location.range` was present (so a real symbol at 0:0 is not treated as partial).
3. Before jump: when `!HasRange` and resolve is advertised, `workspaceSymbol/resolve` with the raw symbol (including `data`). Soft-fail to file start if resolve fails or still lacks a range.
4. `GoToSymbolQueryWindow` (prefilled from the caret); `WorkspaceSymbolsWindow` for multiple hits.
5. Unit tests with frozen JSON (no live language server).

## Release

Ship resolve as a patch after merge (e.g. **0.5.12** via `pwsh scripts/release.ps1`).
